# Evidências

As execuções locais geram uma subpasta por cenário em `execucoes/<data-hora>/`, com PNGs e `resultado.json`. Senhas são mascaradas. Evidências de falhas também são mantidas.

A pasta `validacao-inicial/`, quando presente, contém uma execução histórica publicada. Consulte `docs/RESULTADOS.md` para seu resultado e limites.
